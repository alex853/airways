# VATSIM-бэклог: отчёт и приоритеты

Очередь аэропортов, которых нет в мире, отсортированная по упоминаниям в VATSIM. Как список устроен и как
он используется при создании городов и аэропортов — см. [cities.md](cities.md), раздел «VATSIM-бэклог».
Здесь описан **отчёт** (таблица) и правила приоритета.

## Как получить отчёт

Команда: «дай свежий ватсим-бэклог». Таблица **нигде не сохраняется**, каждый раз собирается заново:

1. `GET /admin/flight-stats/vatsim-top-missing-airports` (токен из `admin-requests.http`, не печатается и не
   сохраняется), `GET /geo/cities`, `GET /geo/airports`.
2. Аэропорты, которые уже есть в `/geo/airports`, исключаются (окно статистики скользящее: 7 суток + сегодня,
   поэтому свежесозданные аэропорты исчезают из списка не сразу).
3. Для остальных считается анализ по `city-population.csv` (города в радиусе 30 nm).

Скрипт отчёта: [`scripts/vatsim_backlog.sh`](../scripts/vatsim_backlog.sh) (`bash scripts/vatsim_backlog.sh [workdir]`),
токен читается из `admin-requests.http` в корне репозитория.

## Формат таблицы

| Колонка | Смысл |
|---|---|
| ICAO | код аэропорта из списка |
| Упом. | число упоминаний в окне |
| Страна (городов в Airways) | страна по `icaodata.csv` и сколько городов этой страны уже в мире |
| Ближайший город в Airways | ближайший город мира и расстояние в nm |
| Анализ по city-population (30 nm) | топ-3 города CSV в радиусе 30 nm: население и расстояние (CSV устарел, при предложении давать свежую оценку рядом) |
| >=100k | число городов ≥100k в 30 nm |
| Σ 25 nm | суммарное население городов в 25 nm |
| Тип | `1: город есть` (ближайший город мира ≤10 nm, нужен только аэропорт), `2: нужен новый город`, `особый` |

`особый`: аэропорта нет в `icaodata.csv` (берётся из refdata, нужен ICAO-код из `added.csv` refdata), либо военный,
либо в 30 nm нет городов CSV (seed-аэропорт).

Над таблицей выводится строка «в списке N записей, уже в мире: …», под ней число записей по типам.

## Приоритеты

- Европа и США берутся в работу только когда аэропорт в самом верху списка, потому что их города уже хорошо
  представлены в мире.
- В первую очередь «тонкие» регионы: Канада, Юго-Восточная и Юго-Западная Азия, Африка, Ближний Восток, острова.
- Если в списке появляется что-либо из **Южной Америки, Юго-Западной Азии или Австралии/Океании** — делаем сразу.
- Следующие кандидаты: Канада (CYVR, CYYC) и TNCM (Sint Maarten, seed-аэропорт без города в CSV).
