# Статистика мира по суткам (2026-11-13)

Раз в сутки, в 00:00 UTC, мир пишет файл со статистикой в папку `./world-stats/` (рядом с `world-data`, в git не попадает). Имя файла это дата суток, которые только что начались: `2026-11-13.json` это состояние на начало 13 ноября. Пишет `WorldStats` (процессор мира, тот же подход, что у ротации статистики аэропортов `Airport2AirportDailyFlightStatRotation`: дата по UTC, срабатывает при смене даты).

**Папку создаёт человек.** Код её не создаёт: если папки нет, в полночь в логе будет `world-stats - unable to write the stats of <дата> to ./world-stats`, а файла за эти сутки не будет. Мир, остановленный в полночь, файл за эти сутки тоже не пишет (при запуске дата берётся из текущей).

JSON написан для чтения человеком (отступы по два пробела, ключи в порядке статусов журни):

```json
{
  "journeys": {
    "LookingForTickets": {
      "journeys": 764224,
      "passengers": 6398516
    },
    "WaitingForCheckIn": {
      "journeys": 0,
      "passengers": 0
    },
    "...": "и так все статусы `Journeys.Status`, статус без журней идёт с нулями"
  }
}
```

`journeys` это число журней в статусе, `passengers` сумма размеров их групп. Сейчас в файле только журни, позже сюда добавится другая статистика (поэтому верхний ключ `journeys`, а не плоский список).

Часовая строка в логе `j/y - stats by statuses ...` (класс `JourneyStats`) убрана: суточный файл её заменяет. Числа те же, что вверху страницы `tech/journeys` (`GET /admin/journey/stats`).
